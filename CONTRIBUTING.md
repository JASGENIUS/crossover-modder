# Contributing

Field notes from crossovers you built are the most useful thing to add (see
[knowledge/README.md](knowledge/README.md)). Fixes to the skills are welcome too, from people and
from agents.

- **Verified facts only.** A number or a behaviour goes in if it was measured in a running game or
  read in the engine's own source. Say which, and give the file and line for source.
- **No game files.** No assets, exports, maps, decompiled or disassembled code, and no copied
  engine scripts. Cite them instead.
- **Nothing for online cheating.** No help with anti-cheat, multiplayer servers you don't run, or
  online services.
- **Keep it plain.** Short sentences, real numbers, symptom then cause then fix.

Open a pull request with a short description of what you built and how you checked it.
