# Field notes

One note per crossover that was actually built. Agents read these before starting, so the next
project doesn't rediscover the same traps.

A note has:

- the exact versions of both games, the mod loaders and the OS;
- the route: which game owns what, how they talk, and why;
- what the engines really do, where it mattered (with source file and line where possible);
- how it was verified in the running games;
- a gotchas table: symptom, cause, fix;
- what's still open.

Name it after the two games (`beamng-minecraft.md`). Only write down what was seen in a running
game or read in the engine's own source, and say which. See [CONTRIBUTING.md](../CONTRIBUTING.md).
